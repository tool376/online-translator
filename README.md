# CyberPortalHub GitHub Translator

Path:
`tools/translator/`

## GitHub Pages
Upload the `tools/translator` folder to your repository and open:

`https://YOUR-USERNAME.github.io/YOUR-REPO/tools/translator/`

For a custom domain:

`https://cyberportalhub.org/tools/translator/`

## Important
This GitHub Pages build is a frontend/demo version. It does NOT contain a Gemini API key.

For production-quality AI translation, connect the frontend to the secure Python/Gemini backend so the API key stays server-side.

Features included:
- Real-time typing translation
- Auto detect
- 50+ languages
- Voice input
- Text-to-speech
- Copy / Clear / Download
- Responsive design

If the public demo translation endpoint is unavailable, the page will show a service-unavailable message.
